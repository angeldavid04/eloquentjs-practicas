# Eloquent JS - Prácticas

Este repositorio contiene código a forma de práctica, usando los ejercicios del libro Eloquent JavaScript 4ta edición 2024 de Marijn Haverbeke, con la traducción al español de Midudev.

Puedes leer el libro en español [aquí](https://www.eloquentjavascript.es/).

## Sobre mí 👋

> Siempre he considerado que programar es una forma de arte, parecido a escribir poemas e ilustrar algo en un lienzo en blanco.<br>Creamos software para que haga las cosas dificiles por nosotros, sin embargo considero que también se trata de crear cosas útiles que puedan ayudar a los demás.
